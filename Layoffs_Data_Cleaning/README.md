Project: Layoffs Dataset - Data Cleaning

Objective:
Clean and prepare a raw layoffs dataset to make it suitable for analysis.

Data Cleaning Steps:
- Created staging tables to preserve raw data
- Identified and removed duplicate records using ROW_NUMBER()
- Standardised company, industry, and country values
- Converted date column to proper DATE format
- Handled null and blank values
- Removed records with no layoff information

Tools:
- MySQL

Outcome:
Produced a clean and consistent dataset ready for exploratory data analysis.
